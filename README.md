# sql-server-ecommerce-portfolio
Diseño e implementación de una base de datos relacional orientada al comercio electrónico utilizando SQL Server (T-SQL). El proyecto abarca desde el modelado relacional hasta la optimización de consultas y automatización con procedimientos almacenados.

## 🛠️ Tecnologías y Habilidades Aplicadas
- RDBMS: SQL Server
- Lenguaje: T-SQL
- Diseño Relacional: DDL, Claves Primarias y Foráneas (`FOREIGN KEY`), Integridad Referencial
- Consultas Avanzadas: DML, `INNER JOIN`, `LEFT JOIN`, `GROUP BY`, `HAVING`
- Programación SQL: Vistas y Procedimientos Almacenados (`STORED PROCEDURES`)

## 📂 Contenido del Repositorio
- `01_schema_design.sql`: Creación de la base de datos, tablas y restricciones relacionales.
- `02_data_insertion.sql`: Inserción de datos de prueba para clientes, productos, categorías y ventas.
- `03_queries_and_analytics.sql`: Consultas analíticas de negocio (top clientes, ventas por categoría).
- `04_views_and_procedures.sql`: Lógica de negocio automatizada (registro de compras, control de stock).
- `05_diagrama_bd.png`: Imagen de la tabla relacional.
